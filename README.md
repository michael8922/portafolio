# Portafolio de Michael Zamorano

Adaptación de la plantilla HTML, Bootstrap y JavaScript entregada por el profesor.

## Vista local

Desde esta carpeta: `python -m http.server 8080`. Abrir http://localhost:8080.

## Abrir en Visual Studio Code

1. Abrir Visual Studio Code.
2. Seleccionar **Archivo → Abrir carpeta**.
3. Elegir la carpeta `Portafolio Michael Zamorano`.
4. Abrir `index.html`.

Para visualizar el sitio se puede usar la extensión **Live Server** y seleccionar
**Open with Live Server** sobre `index.html`. También se puede abrir una terminal
integrada y ejecutar:

```powershell
python -m http.server 8080
```

Luego visitar `http://127.0.0.1:8080`.
