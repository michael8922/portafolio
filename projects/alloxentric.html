Proyecto académico en equipo

Alloxentric

Sistema de agendamiento médico. Mi responsabilidad principal fue modelar e implementar la base de datos y desarrollar el backend.

Python · FastAPI · MongoDB · Vue · Keycloak

Contexto

Proyecto académico en equipo para gestionar el agendamiento médico, con una interfaz web y componentes de chatbot y WhatsApp.

Mi participación

Modelé e implementé la base de datos en MongoDB y desarrollé el backend con Python y FastAPI. Realicé ajustes puntuales en el frontend y apoyé aspectos específicos de la lógica del chatbot.

Otros integrantes lideraron el frontend, la integración del chatbot y la conexión con WhatsApp.

Desafío y solución

Lo más complejo fue definir entidades coherentes con el funcionamiento del sistema e integrar el backend con una plantilla que utilizaba Keycloak. El equipo logró la integración: el frontend envía el token y el backend verifica su firma y los permisos antes de acceder a los recursos.

Aprendizajes

Definir el modelo de datos a partir del flujo de citas y comprender cómo se conectan autenticación, permisos y acceso a datos. La colaboración con el equipo de frontend fue necesaria para resolver la integración.

Estado

Proyecto académico. El código disponible contiene módulos para médicos, citas y configuración. Su funcionamiento actual requiere volver a preparar el entorno y verificar los servicios.
