Proyecto académico en equipo

Gestión de farmacia CESFAM

Sistema de gestión de medicamentos, farmacias y personal. Me encargué del modelado de la base de datos y del backend organizado en capas.

C# · .NET Framework · ASP.NET · ASMX

Contexto

Proyecto académico en equipo para gestionar información de medicamentos, farmacias, farmacéuticos y personal de un CESFAM.

Mi participación

Me encargué del modelado de la base de datos y del desarrollo del backend en C#. Otro compañero se dedicó al frontend.

Arquitectura

El proyecto organiza conexión, objetos de datos, negocio, servicios y presentación en capas. Expone servicios web ASMX de ASP.NET para consultar y modificar información; contiene interfaces de ASP.NET Web Forms y componentes de Windows Forms.

Desafío y aprendizaje

El principal desafío fue poner en funcionamiento los servicios web y conectarlos con la interfaz. Esta experiencia me permitió trabajar con la separación de responsabilidades y la integración entre presentación, servicios y datos.

Estado

Proyecto académico conservado en una copia local. Se revisó parte del código; su ejecución y la integración completa requieren una nueva verificación. El repositorio público todavía no está disponible.
