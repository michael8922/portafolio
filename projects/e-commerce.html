Proyecto personal · En desarrollo

Backend de e-commerce

Backend para productos, categorías, carritos y pedidos. El repositorio Angular contiene la estructura inicial; la integración del frontend está pendiente.

Java 21 · Spring Boot · Spring Security · JPA · MySQL

Contexto y autoría

Proyecto personal desarrollado individualmente para practicar el backend de una aplicación de comercio electrónico. Exploré el frontend con apoyo de ChatGPT; su repositorio conserva la plantilla inicial de Angular.

Implementación disponible

El backend utiliza Java 21, Spring Boot, Spring Security, JPA y MySQL. El código incluye controladores y servicios para autenticación, productos, categorías, carrito y pedidos, con DTOs y mapeadores para organizar el intercambio de datos.

Alcance y próximos pasos

El proyecto está en desarrollo. La integración con Angular está pendiente y las operaciones del backend requieren validación de ejecución. Los próximos pasos son documentar la instalación, verificar los flujos y desarrollar la interfaz.

Por qué lo incluyo

Complementa mi experiencia con Java y Spring Boot y muestra mi interés en entender las relaciones entre catálogo, carrito y pedidos en una aplicación de comercio electrónico.
